👟 SoleMate Shoe Shop POS - User Guide & Setup

Yeh guide aapke counter staff aur store owner ke liye banai gayi hai taake software ko asani se use kiya ja sake.

🚀 1. Desktop Setup & Auto-Start (Server Hamesha Active Rahe)

Server ko 24/7 background mein chalane ke asaan tareeqay:

  1. Desktop Shortcut Banayein: Folder ke andar Setup_Desktop_Shortcut.bat par double-click karein. Aapke Desktop par "SoleMate Shoe POS" ka shortcut ban jayega. Yeh shortcut khamoshi se background mein chalta hai bina kisi black CMD window ke!
  2. Windows Start Hote Hi Khud Chalana (Recommended): Folder mein Enable_AutoStart_With_Windows.bat par double-click karein. Ab jab bhi dukaan ka computer on hoga, POS server khud ba khud background mein chal jayega!
  3. Server Stop / Restart: Agar kabhi server stop karna ho to Stop_POS_Server.bat aur restart karna ho to Restart_POS_Server.bat par click karein.

🛒 2. Counter Billing (Baghair Kisi PIN ke Foran Shuru)

Cashier ya counter staff ko koi PIN daalne ki zaroorat nahi hai. Software khulte hi foran billing ke liye tayyar hai:

  • Barcode Scan: Scanner se jooton ke box par barcode scan karein ya search bar mein naam/brand likhein. Shoe foran cart mein add ho jayega.
  • Size & Color Select: Screen par shoe card par size aur color select karke "Add to Cart" dabayein.
  • Checkout: "Proceed to Payment" dabayein, customer se Cash ya Card lein. Cash ki soorat mein system foran bata dega ke customer ko kitne paise wapas (Change) dene hain.
  • Receipt Print: "Print Receipt" dabayein. 80mm ya 58mm thermal printer par receipt nikal aayegi.

🔒 3. Manager / Owner Mode (Admin PIN)

Dukaan ka munafa (Profits), Cost Price aur Analytics cashier se mehfooz (Hidden) hain:

Admin Mode Unlock karne ka PIN Code:

1234

Jab bhi aap Analytics, Store Settings, ya Add/Delete Shoe par click karenge, system yeh 4-digit PIN maangega. Kaam khatam hone ke baad "Exit to Counter" par click karein taake staff dobara normal billing mode mein aa jaye.

📱 4. Android Phone ya Tablet par chalana (Wi-Fi App)

Agar aap chahte hain ke shop ke andar sales boy mobile par barcode scan kare aur bill banaye:

  1. Apne mobile ko computer wale Wi-Fi ya Hotspot se connect karein.
  2. Computer ki screen par top-right par "Android App" button dabayein. Wahan aapko aapki shop ka Wi-Fi link nazar aayega (Jaise: http://192.168.1.X:8000).
  3. Mobile ke Chrome browser mein yeh link daalein.
  4. Chrome ke 3 dots par click karke "Install App" / "Add to Home screen" par tap karein.
  5. Mobile par app icon ban jayega aur bina kisi browser bar ke poori screen par mobile POS ban jayega!

⚙️ 5. Dukaan Ka Naam Aur Phone Number Badalna

Receipt par apni dukaan ka naam aur contact likhne ke liye:

  • Top menu mein Settings (⚙️) par click karein aur PIN 1234 daalein.
  • Apni shop ka naam, address, mobile number aur Return Policy note likh kar "Save Settings" daba dein.
